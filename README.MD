## 🧠 Prompts


ChatGPT：

|   Ação   | prompt                                                                                                                                                                                                                                                                         |
| :------: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
|  título  | Crie 5 títulos de um e-book sobre o tema azure e devops. O título deve ser épico e curto e que tenha uma temática de Harry Porter.                                                       |
| conteúdo | Explique o que é azure ad, o que é devops e os benfícos de usar azure ad no devops.

{REGRAS}
> Explique sempre de uma maneira simples

> Deixe o texto enxuto

> Sempre traga exemplos de código em contextos reais

> Crie um nome

> sempre deixe um título sugestivo por tópico
